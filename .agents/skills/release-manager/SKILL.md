---
name: release-manager
description: Keep persistent GitHub project memory, safe version history and browser previews.
---
Read PROJECT_STATE, CHANGELOG, asset registry and release policy. Inspect current repo and branch before edits. Store original assets and versioned build sources, keep old previews accessible, archive failed attempts, update manifest/state/change log with test evidence and exact next action. Use descriptive commits; no force push or silent deletion. Publish only when access exists and verify actual URL. Never claim chat-only assets are in Git. Do not commit credentials or unrelated personal information.
