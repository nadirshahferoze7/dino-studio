# DINO Studio

A persistent, code-controlled creative studio for an original dinosaur character and a shared universe spanning animated films, interactive worlds, AR and VR.

## Resume here
1. Read [AGENTS.md](AGENTS.md) for mandatory studio rules.
2. Read [PROJECT_STATE.md](PROJECT_STATE.md) for the current milestone and blockers.
3. Read [docs/CHARACTER_BIBLE.md](docs/CHARACTER_BIBLE.md) and [characters/DINO-001/identity.json](characters/DINO-001/identity.json).
4. Review [CHANGELOG.md](CHANGELOG.md), [docs/ASSET_REGISTRY.md](docs/ASSET_REGISTRY.md), and [docs/ROADMAP.md](docs/ROADMAP.md).
5. Use the reusable skills in [.agents/skills/](.agents/skills/).

The owner approves the creative direction. AI agents perform as much of the technical and creative production as available tools allow. The repository is the durable source of project memory; conversations are not the source of truth.
