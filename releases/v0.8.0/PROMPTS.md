## Background extraction edits
Each generated sheet was passed back to built-in image editing with the instruction to remove only background/shadow/halo, preserve all poses/details/layout and return genuine alpha0 transparency. Edits were inspected; exact original generation bytes are retained in studies, selected edited source PNGs in sources. Image generation/editing is not deterministic; prompt fidelity does not guarantee pixel identity.

## Selection
The sitting sheet changed proportions noticeably from upright to seated; rejected for playback. Supported rising sheet is used forward for rise and backward with different timing for descent. v0.7.4 lowering atlas is reused byte-for-byte at its existing Git path. Early waking uses those accepted poses in reverse, then the newly authored supported rise. No independent waking source generation is claimed.
