# Roadmap
- v0.1 image puppet baseline: built before repository initialization; import archived assets and code.
- v0.2: online studio and corrected palm-forward wave; preserve baseline; inspect motion and request review.
- v0.3: natural blinking, eye gaze and emotional expressions.
- v0.4: natural walk/run and grounded foot contacts.
- v0.5: speech, lip synchronization and secondary scarf/satchel motion.
- v1.0: first approved image-based character animation library.
- Then: cinematic short film, 2.5D exploration, actual 3D environments with image-based characters, AR/VR experiments. Full 3D character only if likeness is demonstrably good. 
- World canon still undecided. Start small and polished; keep reusable characters, environments and motions across formats.

Tools: Python, Pillow, OpenCV, NumPy, SciPy, FFmpeg, Canvas; evaluate PixiJS, Inochi2D, GSAP, Three.js, React Three Fiber/XR, HyperFrames, Remotion (license eligibility), Godot. No external GPU or quota-dependent AI services. AR/VR image sprites have viewpoint/stereo limitations; no immersive implementation yet.
